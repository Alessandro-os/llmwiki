# Primo principio della termodinamica

Appunti della lezione del 14 ottobre.

## Enunciato
La variazione di energia interna di un sistema è uguale al calore assorbito meno
il lavoro compiuto dal sistema: ΔU = Q − L.

## Convenzione dei segni
Q è positivo se il calore entra nel sistema, L è positivo se il lavoro è fatto
dal sistema sull'ambiente. Occhio: alcuni testi di chimica usano il segno opposto
per il lavoro e scrivono ΔU = Q + L.

## Casi particolari
- Trasformazione isocora (volume costante): L = 0, quindi ΔU = Q.
- Trasformazione adiabatica (nessuno scambio di calore): Q = 0, quindi ΔU = −L.
- Trasformazione ciclica: ΔU = 0, quindi Q = L.

## Gas perfetto
Per un gas perfetto l'energia interna dipende solo dalla temperatura:
ΔU = n·cv·ΔT, con cv calore specifico molare a volume costante.
Per un gas monoatomico cv = 3/2 R, per uno biatomico cv = 5/2 R.

Il limite alla conversione di calore in lavoro è nel [[secondo_principio]].
